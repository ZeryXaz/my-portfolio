# My Portfolio

A modern, responsive, and interactive personal portfolio website built with **HTML5**, **CSS3**, and **Vanilla JavaScript (ES Modules)**. This website showcases my profile, projects, technical skills, certificates, and contact information in a clean and professional design.

---

## About

This portfolio was developed to present my academic projects, technical skills, and achievements as an Information Technology student. The website follows a modular structure with reusable components, JSON-based data management, and responsive layouts for desktop and mobile devices.

## Installation

Clone the repository

```bash
git clone https://github.com/ZeryXaz/my-portfolio.git
```

Go to the project directory

```bash
cd my-portfolio
```

Open with Live Server or any local web server.

---

## Deployment

This project can be deployed easily using **Vercel**.

1. Import the GitHub repository.
2. Framework Preset: **Other**
3. Deploy.
